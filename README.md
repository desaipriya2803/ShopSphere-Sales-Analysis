# ShopSphere Sales Analysis

## Project Overview

ShopSphere Sales Analysis is a data analytics project using Excel, SQL, and Power BI.

## Tools Used

- Microsoft Excel
- MySQL
- Power BI
- GitHub

## Project Workflow

Raw Data → Excel Cleaning → SQL Analysis → Power BI Dashboard

## Key Analysis

- Total Revenue
- Total Orders
- Average Order Value
- Revenue by Category
- Revenue by City
- Revenue by Product
- Order Status Analysis

## Key Results

- Total Revenue: ₹85,870
- Total Orders: 30
- Average Order Value: ₹2,862.33
- Highest Revenue Category: Electronics
- Highest Revenue City: Pune
- Highest Revenue Product: Monitor
